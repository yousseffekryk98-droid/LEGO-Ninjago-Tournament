# Visual asset sources and policy

This fan remake does not copy assets from the original APK/OBB. Most authored 3D geometry is clean-room project art; explicitly listed open-license third-party geometry is kept under its own license and attribution and must never be represented as MIT-licensed project art.

## Bundled assets

- `src/features/characters/icons.ts` — original, code-generated fighter SVG badge icons. Covered by this repository's MIT license.
- `src/features/characters/portraits.ts` — original Three.js renders made from the project's procedural fighter geometry, with explicit local overrides for user-supplied Lloyd/Kai/Jay look references.
- `public/icons/minifigure-silhouette.svg` — original clean-room block-toy/minifigure silhouette. Covered by this repository's MIT license.
- Procedural Three.js fighter geometry in `src/shared/three/minifigure-model.ts` — original project geometry.
- `scripts/generate-authored-assets.mjs` — original clean-room source that generates the local Chen center-pillar GLB used by the arena GLB pipeline. The generated binary is intentionally not committed.
- `scripts/generate-chen-gate.mjs` — original clean-room Chen gate GLB generator.
- `scripts/generate-arena-props.mjs` — original clean-room serpent-column and gong GLB generator.
- `scripts/generate-core-fighters.mjs` — original clean-room authored-body GLB generator for the main ninja, Garmadon, Chen and Skylor; procedural accessories remain the fallback/secondary detail layer.
- `third_party/ldraw-stl/*.stl` — LDraw-derived exact minifigure mould geometry used by production Lloyd. These files are third-party CC BY material, not MIT project art; see `third_party/ldraw-stl/LICENSE` and `third_party/ldraw-stl/ATTRIBUTION.md`.
- `scripts/generate-lloyd-exact-production.mjs` — project-authored assembly/decoration generator that combines those attributed moulds with original Tournament-robe detail geometry and writes `lloyd-tournament.glb` last in the normal build pipeline.
- `public/assets/reference/lloyd-user-reference.webp`, `kai-user-reference.webp`, and `jay-user-reference.webp` — cropped character-look images supplied directly by the project owner in the development conversation for roster/HUD presentation. They are not generated by this repository and are not covered by the repository's MIT license; their upstream provenance/license was not supplied.

## Character likeness rule

Named fighters may use the project's own colors, gameplay data, text names, and clean-room procedural geometry. Do not bundle official LEGO/NINJAGO logos, extracted textures, voice/audio, animations, screenshots, or copied meshes.

When a third-party asset is added later, record:
1. exact source URL;
2. creator/uploader;
3. exact license;
4. whether modified;
5. the repository path where it is used.
