LEGO Ninjago Tournament Fan Remake

Ninja Tournament is a browser-playable 3D fan project inspired by the discontinued 2015 mobile arena brawler. It recreates the style of tournament combat through independently written code and original/procedural project assets.

Play in browser View source on GitHub

Current game features

51 playable fighters
A broad roster with fighter-specific stats, styles and elemental combat themes.
Elemental combat
Fighter-themed kicks, melee combat, Spinjitzu and a Tornado of Creation team ultimate in Free Play.
Progression
Earn studs, permanently upgrade fighters, increase damage and speed, and unlock extra maximum hearts at higher levels.
Multiple modes
Tournament, Challenge, Dojo, Fighters, Gallery, loadout and control systems.
Cross-input play
Keyboard, remappable controls, standard gamepads and mobile touch input.
Browser-first
Built as a Progressive Web App with a Capacitor Android packaging path.

Technology and development

The project is built with TypeScript, Vite and Three.js. Automated browser testing uses Playwright, while Capacitor provides the Android packaging path.

The source repository includes contributor guidance, a roadmap, security policy, issue templates and clean-room rules for community contributions.

Clean-room and intellectual-property policy

This project does not distribute extracted APK/OBB files, proprietary source code, ripped official models, textures, logos, music, sound effects, animations or other unauthorized assets from the discontinued commercial game.

Open-source contribution

Contributors can help with original 3D art, VFX, combat polish, accessibility, gamepad/touch controls, responsive UI, performance, automated tests, documentation and translations.

Frequently asked questions

An unofficial clean-room, open-source 3D browser fan remake inspired by the discontinued 2015 LEGO Ninjago Tournament mobile arena game.

No. It is a fan project and is not affiliated with or endorsed by LEGO or the original game's developers or publishers.
