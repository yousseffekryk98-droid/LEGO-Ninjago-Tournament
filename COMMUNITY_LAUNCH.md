## r/gamedev

Title:

**What I learned rebuilding a discontinued mobile arena game in Three.js without using its original assets**

Body:

I have been rebuilding the feel of a discontinued 2015 mobile arena game as a clean-room browser project using TypeScript, Vite, and Three.js.

The interesting problems have been less about copying content and more about reconstructing the systems from observation: readable arena camera framing, touch + keyboard + controller input, input buffering, lightweight minifigure animation rigs, WebGL performance on laptops/phones, combat feedback, persistent progression, and keeping one codebase responsive across devices.

The current project has grown to 51 playable fighters, elemental combat, challenge modes, health/stud pickups, character progression, and a large multi-character team special.

I am opening the repository because I would especially value technical feedback on:
- keeping Three.js fighter rigs lightweight as visual detail increases
- keeping action input responsive under low frame rates
- balancing WebGL visual effects against low-end mobile performance
- structuring gameplay features so contributors can add content without creating duplicate systems
